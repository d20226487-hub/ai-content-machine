# Публикация на сайты фильмов

Пошаговая инструкция: как обновить фильмы, категории и добавить комментарии на сайтах фильмов. Доступно админам и менеджерам.

Сайты фильмов принимают данные через свой CSV-импорт (`https://домен/import/api.php`). Система сама собирает CSV из строк вашей таблицы и отправляет его — вручную ничего выгружать не нужно.

## Что можно публиковать

| Что | Что происходит | Как сайт находит запись |
|---|---|---|
| **Фильм** | обновляет существующий фильм | по Kinopoisk ID, затем по точному Title |
| **Категория** | обновляет существующую категорию | по ID, затем slug, затем названию |
| **Комментарий** | добавляет комментарии к фильму | по ссылке на фильм или его точному названию |

Новые фильмы и категории отсюда **не создаются** — только обновляются уже существующие на сайте.

## Шаг 1. Один раз: логин и пароль

**Настройки → Публикация → Фильмы.** Введите логин и пароль от импорта и нажмите **Сохранить**.

Они общие для всех сайтов фильмов и не совпадают с паролем Custom CMS. Если пароль поменяется — просто сохраните новый: он сразу применится ко всем сайтам фильмов. После сохранения пароль не показывается.

## Шаг 2. Один раз: добавить сайты

**Публикация → Домены → Добавить домен → Фильмы → Продолжить.** Вставьте домены по одному в строке, без языков:

```
lordfilms.click
another-films-site.net
```

Нажмите **Добавить**. Сайт появится в списке с жёлтой меткой **films**.

## Шаг 3. Подготовить таблицу

Нужна bulk-таблица, где **одна строка = одна запись** (один фильм, одна категория или комментарии к одному фильму). Удобно завести колонку **Site** с доменом — тогда окно публикации само поймёт, что это таблица для сайта фильмов.

Готовые примеры есть в разделе `/library`: **Import CSV → Download sample ▾ → Фильмы — …**. Или скачайте их отсюда, поправьте и загрузите через **Import CSV**:

- [Фильмы — обновление](/samples/films-update.csv)
- [Категории](/samples/films-categories.csv)
- [Комментарии](/samples/films-comments.csv)

Тексты (описания, meta, комментарии) обычно генерируются промптами в выходных колонках — публиковать можно любые колонки таблицы.

Какие колонки понадобятся:

**Фильм.** Обязательно: **Title** — точное название на сайте (по нему фильм ищется, если нет Kinopoisk ID). Желательно: **Kinopoisk ID** — самый надёжный способ найти фильм. Что обновить — любые из: Meta Title, Meta Description, Краткое описание, Полное описание, H1, Poster URL.

**Категория.** Чтобы найти: хотя бы одно из **Category ID**, **Category Slug**, **Category Name**. Что обновить — хотя бы одно из: Category Description, Category Meta Title, Category Meta Description, Category Bottom Description.

Где эти тексты видны на странице категории:

- **Category Description** — описание **сверху**, до карточек фильмов.
- **Category Bottom Description** — описание **внизу**, после карточек фильмов.
- **Category Meta Title** и **Category Meta Description** — на странице не видны, это title и description для поисковиков.

**Комментарий.** Чтобы найти фильм: **Film URL** (например, `/the-godfather-buck.html`) или **Film Name** (точное название). Сами комментарии — пары **Author 1 / Comment 1** … до **Author 5 / Comment 5**.

## Шаг 4. Запустить публикацию

1. Откройте таблицу и нажмите **Массовая публикация**.
2. Если в таблице есть колонка с доменом сайта фильмов, окно откроется сразу на **Фильмы** с выбранным сайтом. Если нет — выберите тип CMS **Фильмы** вручную.
3. **Режим:** **Один сайт** — все строки уходят на выбранный сайт; **Несколько сайтов** — каждая строка на свой сайт, укажите **Колонку с доменом**.
4. **Тип страницы:** Фильм, Категория или Комментарий. Операция подставится сама (для фильмов и категорий — «Обновить», для комментариев — «Создать»).
5. **Сопоставление полей:** для каждого поля выберите колонку таблицы. Ненужные оставьте «— пропустить —».
6. При необходимости ограничьте строки (**Выбранные** или **Диапазон**) и нажмите **Запустить**.

Если не сопоставлено обязательное поле, окно подскажет, какое, ещё до запуска.

## Что важно знать

- **Пустая ячейка ничего не стирает.** На сайт уходят только заполненные ячейки. Можно обновить одно поле — остальные на сайте останутся как были.
- **Film URL — последняя часть адреса фильма без номера,** как `alt_name` в базе сайта: `/the-godfather-buck.html`. Если в таблице полная ссылка или адрес с номером (`https://site.com/1671-the-godfather-buck.html`), система сама приведёт его к виду `/the-godfather-buck.html`.
- **Пустые пары комментариев пропускаются,** остальные нумеруются подряд.
- **Каждая строка — отдельный запрос,** поэтому у каждой строки свой статус и своя причина ошибки.
- ID и адрес записи сайт не возвращает, поэтому колонок для обратной записи здесь нет.

## Проверка результата

После запуска откроется страница прогона со статусом каждой строки. Частые причины ошибок:

| Сообщение в строке | Что сделать |
|---|---|
| `Skipped: film not found by Kinopoisk ID or exact title.` | проверьте ID и написание названия — оно должно совпадать с сайтом символ в символ |
| `Skipped: category not found by ID, slug or name.` | проверьте slug/название категории на сайте |
| `Skipped: film not found by URL or exact title.` | проверьте ссылку на фильм или его название (комментарии) |
| `401 — wrong login/password for this Films site.` | исправьте логин/пароль в **Настройки → Публикация → Фильмы** |
| `Title is required…` / `A category needs its ID, slug or name…` | в строке пустая ячейка у обязательного поля — заполните её |

Откройте строку, чтобы увидеть, что именно было отправлено, и готовую команду curl для ручной проверки (пароль в ней скрыт). Подробный журнал сайт пишет у себя в `import/logs/import.log`. Неудачные строки можно отправить повторно кнопкой **Повторить неудачные**.

Справочные подробности — в разделах [Публикация: массовая](/docs/publish-bulk) и [Публикация: домены и подключение](/docs/publish-domains).
