# Промпты, папки, теги, версии

Раздел `/prompts` — библиотека всех текстовых заготовок, по которым работает Single и Bulk. Промпт — это шаблон с переменными, который превращается в готовый запрос к модели после подстановки значений.

## Как устроена страница

Сверху расположена панель с хлебными крошками (`Home / Папка / Подпапка`), поиском, фильтром по тегам и кнопками **+ Новая папка**, **Управление тегами** и **+ Новый промпт**.

Ниже — карточки папок, а под ними список промптов.

- **На корневой странице** по умолчанию показываются **все промпты во всех папках**. Поиск и фильтр по тегам работают глобально.
- **Внутри папки** появляется переключатель «Включая подпапки» — включите его, если хотите видеть промпты не только из текущей папки, но и из вложенных.

Состояние страницы сохраняется в адресе. Можно скопировать URL и поделиться им — коллега увидит ту же выборку.

## Создание промпта

Нажмите **+ Новый промпт**. Форма:

- **Название** — короткое, по сути.
- **Папка** — куда положить.
- **Теги** — можно выбрать существующие или создать новые прямо здесь.
- **Содержимое промпта** — сам текст.

### Переменные

Внутри текста промпта используйте двойные фигурные скобки: `{{topic}}`, `{{audience}}`, `{{tone}}`. Любая такая «дырка» автоматически становится переменной. Список переменных вычисляется по содержимому — отдельно описывать его не нужно.

В Single Вы заполните эти переменные руками. В Bulk каждая переменная сопоставляется с колонкой таблицы.

### AI-assist при создании

В форме создания есть кнопка **Сгенерировать черновик с помощью AI**. Откроется модальное окно: укажите краткое описание задачи, выберите провайдера и модель — система сама напишет первый вариант промпта. Дальше Вы его правите вручную.

## Папки

Папки организованы деревом: одна папка может содержать другие. На карточке папки видно, сколько в ней промптов и сколько подпапок. При наведении появляются кнопки **Переименовать** и **Удалить**.

Удалить непустую папку нельзя — сначала перенесите или удалите её содержимое.

## Теги

Теги — плоский список (без иерархии). Один промпт может иметь сколько угодно тегов. Фильтр по тегам в верхней панели работает по логике «И»: если выбрано три тега, останутся промпты, у которых есть **все три**.

Полное управление тегами — на странице `/prompts/tags`. Там можно:

- переименовать тег;
- объединить два тега (**Merge**) — все промпты с тегом-источником будут перепомечены целевым тегом, а исходный тег удалится;
- удалить неиспользуемый тег.

## Версии

Каждое сохранение содержимого промпта создаёт **новую версию**. Старые версии не теряются и не перезаписываются.

На странице промпта Вы видите:

- **Текущую версию** — её используют Single и Bulk по умолчанию.
- **Историю версий** — список всех предыдущих сохранений с датой и автором.

Что можно делать с версией:

- **Открыть** — посмотреть содержимое.
- **Редактировать примечание** (`change_note`) — короткий комментарий «что поменялось», его можно править ретроспективно.
- **Откатить** (`Revert`) — сделать выбранную старую версию снова текущей. При этом создаётся ещё одна новая версия с тем же содержимым; ничего не теряется.

В bulk-таблицах сохраняется **номер версии**, который использовался при генерации, — и в случае отката Вы всегда сможете понять, какой именно текст был использован.

## Перемещение и удаление

- **Перенести** промпт в другую папку — кнопка **Move** на карточке. Откроется выпадающий список всех папок.
- **Удалить** — обычная кнопка удаления. Промпт исчезает целиком вместе со всей историей версий.

Удаление промпта **не удаляет** уже сделанные генерации в Single или ячейки в Bulk — там остаётся снимок текста. Но запустить новую генерацию по удалённому промпту нельзя.
