# Bulk — таблицы массовой генерации

Раздел `/library` (в меню — **Bulk**) — это таблицы. Каждая строка — отдельная задача, каждая колонка — либо вход (переменные), либо выход (генерируемый текст). Используйте Bulk, когда нужно получить десятки или сотни результатов по одной и той же логике.

## Список таблиц

`/library` устроен как `/prompts`: папки сверху, таблицы — карточками. Поиск, фильтр по папкам, пагинация — всё работает так же.

- **+ Новая папка** — создаёт папку. Папки в Bulk **плоские**: вложить одну папку в другую нельзя.
- **+ Новая таблица** — создаёт пустую таблицу. Дайте имя и при желании опишите назначение.
- **Move** на карточке — перенести таблицу в другую папку.
- **Duplicate** — копия таблицы со всеми колонками (без значений ячеек).

### Кто что видит

- **content_generator** видит только свои таблицы.
- **admin** и **manager** видят все таблицы. Удалять чужие таблицы может только администратор; менеджеры могут открывать и править, но не удалять.

## Внутри таблицы

Откройте таблицу — увидите редактор:

- **Колонки** идут слева направо. У каждой колонки есть тип: **input** (хранит значения переменных) или **output** (туда генерируется текст).
- **Строки** добавляются кнопкой **+ Row**. Можно добавить пакетом — система предложит ввести количество.
- **Ячейки** редактируются двойным щелчком: открывается окно с вкладками **Edit** и **Preview**.

### Колонки

Чтобы добавить колонку — кнопка **+ Column** в правой части шапки. Над каждой колонкой в шапке при наведении появляются три кнопки:

- **⚙ Configure** — настроить колонку.
- **⇄ Kind** — переключить input ⇄ output.
- **× Delete** — удалить колонку.

Переименовать колонку — двойной клик на её имени.

#### Настройка output-колонки

В output-колонке можно задать:

- **Промпт** — какой шаблон использовать для генерации.
- **Сопоставление переменных** — каждой `{{variable}}` промпта указывается input-колонка, откуда брать значение для конкретной строки.
- **Провайдер и модель** — необязательно. Если не задано — берётся первый включённый провайдер с ключом. Полезно, например, отдать дешёвой модели заголовки, а дорогой — основной текст.

### Ячейки

Состояние ячейки видно по цвету и иконке:

- **empty** — пусто.
- **manual** — заполнено вручную.
- **generating** — сейчас генерируется.
- **generated** — успешно сгенерировано.
- **failed** — ошибка. Кликните по ячейке — увидите подробности и кнопку **Retry this cell**.

Двойной клик по ячейке открывает редактор. Edit — текстовое поле, Preview — рендер HTML-результата (для output-колонок).

## Автосохранение

Изменения сохраняются автоматически с задержкой ~600 мс после последнего ввода. В правом верхнем углу видно состояние: **Saving…** или **Saved**.

Можно спокойно переключаться между ячейками и закрывать вкладку — данные сохранятся.

## Импорт и экспорт

Кнопка **Import CSV** загружает значения в таблицу: первая строка — заголовки, дальше данные. Если заголовок совпадает с именем существующей колонки — данные уйдут туда; новые имена создадут новые input-колонки.

В окне импорта есть выпадающее меню **Download sample ▾** — четыре готовых шаблона CSV под основные сценарии публикации: WordPress (один сайт / несколько сайтов) и Custom CMS (один сайт / несколько сайтов). Удобно, если вы только начинаете и хотите увидеть, какие колонки в каком случае нужны. Для Custom CMS колонки в шаблоне отражают плейсхолдеры `body_template` существующего тестового домена — на вашем домене они могут отличаться.

**Export CSV** скачивает текущее состояние таблицы целиком.

## Запуск генерации

В верхней части таблицы есть кнопка **Generate…**. Она открывает окно:

- **Колонка** — какую output-колонку обрабатывать. В списке только output-колонки, у которых задан промпт.
- **Строки**:
  - **All** — все строки.
  - **Selected** — выделенные через чекбоксы.
  - **Range** — диапазон по позиции, например `1–50`.
- **Фильтр ячеек**:
  - **Only empty** (по умолчанию) — пропустить уже сгенерированные.
  - **Only failed** — повторить только те, что упали.
  - **All overwrite** — перегенерировать всё, в том числе уже готовые.
- **Превью** — система покажет «Будет сгенерировано N ячеек» с учётом выбранных фильтров.

После подтверждения запросы становятся в очередь Celery и обрабатываются параллельно с учётом лимитов провайдера. Таблица каждые 1.5 секунды опрашивает статус, ячейки переходят из **generating** в **generated** или **failed** на глазах.

## Управление видом таблицы

Эти настройки сохраняются в Вашем браузере — каждая таблица помнит их отдельно:

- **Ширина колонок** — потяните за правый край шапки колонки.
- **Высота строк** — Compact / Default / Comfortable / Tall.
- **Размер страницы** — 5 / 10 / 20 / 50 / 100 / 200 / 500 / 1000 строк.
- **Пагинация** — снизу таблицы.

## Полезные действия с выделением

Если выделить несколько строк чекбоксами, появится панель действий:

- **Clear values** (красная кнопка) — очищает значения во всех ячейках выделенных строк. Сами строки при этом остаются.
- Удаление строк — крестик в начале строки или у каждой строки в режиме просмотра.

Колонки удаляются индивидуально, **массового удаления колонок нет**.

## Корзина (Trash)

Удаление таблицы — теперь **soft-delete**: она попадает в Корзину, а не пропадает безвозвратно. Это защита от случайных кликов по красной кнопке.

- На странице `/library` сверху появляется ссылка **Корзина (N)**, когда в ней есть таблицы.
- На `/library/trash` — список удалённых таблиц: имя, размер (колонки × строки), кто и когда удалил.
- Кнопки по каждой строке:
  - **Просмотр** — открывает таблицу в режиме read-only (первые 100 строк). Редактировать нельзя — для этого нужно сначала восстановить.
  - **Восстановить** — возвращает таблицу в активный список. Если папка, в которой она лежала, успели удалить — таблица восстанавливается без папки.
  - **Удалить навсегда** — безвозвратное удаление со всеми колонками, строками, ячейками и связанными прогонами публикации.
- Множественные действия — чекбоксами слева плюс кнопки **Восстановить выбранные** / **Удалить выбранные** / **Очистить корзину** сверху.
- Прямой URL `/library/<id>` для удалённой таблицы **не работает** (404). Открыть её можно только из Корзины.

### Защита от удаления во время публикации

Если по таблице идёт активный прогон Bulk Publish (статус `queued`, `running` или `paused`), удалить её нельзя — будет ошибка 409 с предложением сначала отменить или дождаться окончания прогона на `/publish/runs`.

### Автоочистка корзины

По умолчанию таблицы лежат в Корзине **50 дней**, потом удаляются безвозвратно. Срок настраивается администратором на `/settings` → **Срок хранения корзины таблиц**. Значение `0` отключает автоочистку — таблицы остаются в Корзине, пока их не удалят руками. Проверка идёт раз в сутки фоновой задачей (03:15 UTC); если нужно очистить раньше — кнопка **Очистить корзину** на `/library/trash`.

## Если упали ячейки

Откройте такую ячейку — будет подробная ошибка, та же, что в журнале `/errors`. Возможные причины:

- кончились квоты у провайдера (429);
- сетевая ошибка или таймаут (5xx);
- неправильно настроено сопоставление переменных (например, в input-колонке пусто).

Кнопка **Retry this cell** попытается ещё раз без обращения к Generation Queue — это быстрый путь для одной упавшей ячейки. Для нескольких — лучше перезапустить через **Generate…** с фильтром **Only failed**.
