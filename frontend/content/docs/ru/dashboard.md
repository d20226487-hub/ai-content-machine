# Обзор и навигация

Этот раздел отвечает на главный вопрос: где что находится в системе и какие разделы доступны для каждой роли.

## Главное меню

Сверху у каждой страницы есть единая панель навигации. Состав пунктов зависит от роли:

| Раздел | Адрес | Кому доступен | Зачем нужен |
|---|---|---|---|
| Dashboard | `/dashboard` | всем | стартовая страница, статус API, ссылка на документацию |
| Prompts | `/prompts` | всем | библиотека промптов с папками, тегами и историей версий |
| Single | `/create` | всем | разовая генерация по одному промпту |
| Bulk | `/library` | всем | таблицы для массовой генерации |
| Publish | `/publish` | admin, manager | публикация в WordPress или Custom CMS |
| Users | `/users` | admin, manager | управление пользователями |
| Errors | `/errors` | admin, manager | журнал ошибок |
| Settings | `/settings` | admin | провайдеры, цены, бэкапы, корзина, «Мозг» (вкладки) |
| Docs | `/docs` | всем | эта документация |

Если у Вас нет доступа к разделу — пункт меню просто не отображается.

## Три роли и за что они отвечают

**admin** — полный доступ. Только администратор может настраивать ключи LLM-провайдеров и менять системные параметры в `/settings`.

**manager** — всё, кроме настроек провайдеров. Может управлять пользователями, доменами публикации, видеть журнал ошибок, заходить в чужие bulk-таблицы для просмотра и правки. Не может удалять чужие bulk-таблицы и понижать/удалять администраторов.

**content_generator** — основная рабочая роль. Видит свои bulk-таблицы и сохранённые генерации. Не имеет доступа к публикации, пользователям, ошибкам и настройкам.

## С чего начать

1. **Откройте `/prompts`** и убедитесь, что в системе уже есть нужные Вам промпты. Если нет — создайте их.
2. **Single (`/create`)** удобен, когда нужно быстро получить один результат: например, один заголовок или одну статью.
3. **Bulk (`/library`)** нужен, когда требуется получить десятки или сотни результатов по одному и тому же промпту с разными входными данными — это таблица, где каждая строка обрабатывается независимо.
4. **Сохранённые генерации** в Single можно открыть позже и при необходимости отправить на публикацию (если у Вас есть права).
5. **Publish** позволяет отправить готовый текст в WordPress или другой CMS — поодиночке или массово.

## Внешний вид и настройки интерфейса

В правом верхнем углу есть переключатели:

- **Тема** — Светлая / Тёмная / Системная (сохраняется в браузере).
- **Язык** — английский / русский (сохраняется в браузере).

Настройки персональные: они влияют только на Ваш браузер и не передаются другим пользователям.

## Если что-то не работает

- Сначала проверьте раздел **Status** на Dashboard: если API недоступен, действия в системе будут заканчиваться ошибкой.
- Управляющие и администраторы могут открыть **Errors** и посмотреть детали последних сбоев — там видны как серверные ошибки, так и ошибки клиентской части.
- Если нужная функция не появляется (например, кнопка публикации) — почти всегда дело в роли. Проверьте, под каким аккаунтом Вы вошли.
