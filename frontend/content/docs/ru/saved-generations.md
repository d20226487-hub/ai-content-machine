# Сохранённые генерации

Любую успешную генерацию в Single можно сохранить кнопкой **Save**. Сохранение хранит:

- сам результат (текст);
- какой промпт и какая его версия использовались;
- значения всех переменных, которые Вы вводили;
- провайдер и модель.

Сохранения **персональные** — другие пользователи их не видят.

## Где смотреть сохранения

Сохранённые генерации живут на отдельной странице `/create/saved` (раньше это было модальное окно). Ссылка на неё есть на форме Single (`/create`). Список постраничный, с поиском; в каждой строке — имя, промпт, его версия, провайдер/модель и дата.

Для каждой записи доступно:

- **Open** — открывает сохранение на странице результата `/create/output`. Все поля (промпт, переменные, результат) восстанавливаются точно в том виде, в каком были сохранены.
- **Rename** — переименовать (правка прямо в строке).
- **Delete** — удалить (с подтверждением).

## Что происходит при открытии

При нажатии **Open** сохранение снова отрисовывается на `/create/output` — это режим просмотра ранее полученного результата.

Можно:

- Скопировать текст.
- Открыть результат в отдельном окне (sandbox-iframe внутри popup).
- **Перевести** результат (см. раздел «Перевод контента»).
- Если у Вас есть права на публикацию — нажать **Publish to…** и отправить именно этот текст в домен.

## История публикаций

В режиме просмотра под текстом отображается блок **Published to** — список публикаций именно этой генерации. Удобно понять: эта статья уже улетала в WordPress? Когда? На какой домен? Какой получился URL поста?

Если ни разу не публиковалась — блок пустой.

## Связь с промптом

Сохранение помнит **номер версии промпта**. Если промпт после этого редактировался — `current_version` уже другая, но Вы всё равно видите тот текст, который реально использовался. Это важно для воспроизводимости.

Если промпт удалён, сохранение остаётся: имя промпта хранится в виде снимка (`prompt_name_snapshot`), а ссылка на сам промпт становится пустой.

## Когда удалять

Сохранения занимают место в базе. Имеет смысл удалять:

- черновики, которые Вы переделывали много раз;
- результаты, уже опубликованные и больше не нужные;
- любые тестовые запуски.

Если результат уже опубликован — удаление сохранения **не отзывает публикацию**, оно лишь убирает локальную копию у Вас в Single.
