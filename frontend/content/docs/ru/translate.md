# Перевод контента

Любой сгенерированный текст можно перевести на другой язык **на месте**, не покидая экран. Перевод нужен, чтобы коллега, не знающий язык оригинала, мог прочитать и проверить контент. Работает через отдельный системный промпт, который настраивает администратор (см. ниже).

## Перевод в bulk-таблицах

Главный сценарий — перевод output-ячейки прямо в редакторе:

1. Дважды кликните по ячейке — откроется редактор.
2. Перейдите на вкладку **Preview** (в режиме **Edit**, пока вы правите текст, кнопка скрыта — перевод относится к готовому значению, а не к черновику).
3. Нажмите **Перевести**. Окно расширится и покажет два столбца: слева **Оригинал**, справа **Перевод**.

### Выбор языка

В панели перевода есть выпадающий список **Популярные языки** (русский, английский, украинский, польский, немецкий, французский, испанский, итальянский, португальский, турецкий, китайский). Если нужного нет — выберите **Свой…** и введите код языка (например, `cs`, `nl`).

Выбранный язык **запоминается в вашем браузере** и подставляется по умолчанию в следующий раз. Порядок выбора языка по умолчанию: ваш прошлый выбор → язык из настроек «Мозга» → `ru`.

### Кэширование

Готовый перевод **сохраняется в самой ячейке** (по коду языка). Повторное открытие того же языка ничего не стоит — текст берётся из кэша. Кнопка **Перевести заново** (`force`) обходит кэш и переводит ещё раз.

Кэш привязан к текущему значению ячейки: как только значение меняется — генерацией, «Найти и заменить», ИИ-исправлением ссылок или ручной правкой — старый перевод **сбрасывается автоматически**, чтобы вы не читали перевод устаревшего текста.

## Перевод на других экранах

Та же панель перевода доступна и вне bulk-таблиц:

- **Single → результат** (`/create/output`) — кнопка **Перевести** рядом с результатом. Для сохранённой генерации перевод запоминается; для несохранённого черновика перевод разовый (нигде не кэшируется).
- **Страница промпта** (`/prompts/<id>`) — переводит текущую версию промпта. Версии неизменяемы, поэтому их перевод кэшируется навсегда.
- **Тест промпта → результат** (`/prompts/<id>/test/output`) — переводит разовый тестовый ответ (без сохранения).

## Настройка перевода (администратор)

Поведение перевода задаётся в **Настройки → вкладка «Мозг» → Промпт для перевода**:

- **Системный промпт** — как именно переводить. Плейсхолдер `{{target_language}}` подставляется выбранным языком; значение ячейки/текста уходит моделью как сообщение пользователя.
- **Язык перевода по умолчанию** — двухбуквенный код (например, `ru`), который подставляется в редакторе, пока пользователь не выбрал свой.
- **Провайдер ИИ для перевода** — какой провайдер и модель использовать. Пусто = первый включённый провайдер и его модель по умолчанию. Обычно сюда ставят дешёвую быструю модель.

> Подробнее про вкладку «Мозг» — в разделе «Настройки».
